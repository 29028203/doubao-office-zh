# 豆包工作上多Agents并行和Mac操作电脑：一个任务拆给多个AI同时干

> 原文链接：[https://www.laoshoucun.com/traeworkdt/3016](https://www.laoshoucun.com/traeworkdt/3016)

<p>9月2日，<a href="https://www.laoshoucun.com/traework" target="_blank" rel="noopener">豆包</a>工作上线了两项新能力：多Agents并行，以及Mac系统下的操作电脑。这是豆包工作8月25日作为字节AI办公统一入口发布之后的第一次大版本更新。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/09/20260904185931_856122.png" alt="豆包工作多Agent并行"></p>
<p>多Agents并行解决的是任务多、要同时干的问题。以前让AI干活，通常是一个Agent从头做到尾，现在<a href="https://www.laoshoucun.com/traework" target="_blank" rel="noopener">豆包</a>可以在一个大任务下召唤多个子Agent，各自负责一个模块。比较典型的场景是同时做市场调研、竞品分析和内容初稿：以前这些活得排队一个个来，现在能并行跑，几个模块一起交付。拆任务的思路也简单，一个目标底下几块互不搭界的活，最适合拆开并行，前后咬合、必须按顺序来的步骤，硬拆反而添乱。</p>
<p>Mac下的操作电脑是另一套能力。它走的是本地GUI操作路线，不需要MCP，不需要API，也不需要插件和CLI，AI直接看屏幕界面完成操作，点按钮、填表单都在桌面上进行。对说不清接口、但看着界面就会点的普通用户，这类活现在可以交给AI。</p>
<p>两个功能放一起，能看出<a href="https://www.laoshoucun.com/traework" target="_blank" rel="noopener">豆包</a>工作想走的路线：它不打算只做一个聊天框，而是在豆包的品牌和模型前面，不断把AI能干的活从对话扩展到真实操作。前台靠豆包已有的用户基础，后台靠操作能力一点点铺开。</p>
<p>对已经在用<a href="https://www.laoshoucun.com/traework" target="_blank" rel="noopener">豆包</a>的人，或者正在对比各家AI办公工具的人，要试就先试多Agents并行，拿一个手头真实的任务拆开跑跑看，跟以前排队等的感觉差别挺明显。操作电脑目前只支持Mac，Windows用户要等官方后续版本。</p>
