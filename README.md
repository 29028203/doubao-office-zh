## 豆包办公介绍

TraeWork（也叫豆包办公）是字节跳动 TRAE 战略产品团队自研的 AI 智能体工作台产品线，现已并入豆包团队。它是一款 AI 原生一体化工作台，面向个人、团队、研发人员打造全场景生产力平台，提供网页端、桌面端、移动端三端同步协同能力，内置 Work、Code、Design 三大独立工作模式，分别适配普通办公、代码开发、视觉设计三类需求场景。依托智能体自动拆解任务、调用技能库执行文档撰写、PPT 制作、代码调试等工作，支持 MCP 协议外接第三方工具拓展能力，统一工作空间管理全部项目文件，实现非技术人员与开发者共用一套平台完成工作，适配产研团队上下游协同办公。

## 豆包办公特点

- 网页、桌面、移动端互通，任务数据实时跨端同步。
- AI 自主拆解执行任务，用户仅需关键节点验收。
- MCP 协议开放扩展，灵活接入各类第三方工具。
- 统一项目工作空间，集中管理文件，减少工具跳转。
- 三大独立工作模式，覆盖办公、开发、设计全场景。
